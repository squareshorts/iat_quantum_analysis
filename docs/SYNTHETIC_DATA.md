# Synthetic Life-satisfaction IAT Data

The independent life-satisfaction IAT was collected under a separate ethics protocol. The participant-level raw data cannot be shared openly because the consent and ethics approval for the original study did not authorize unrestricted public release of participant-level behavioral data.

To support code review, this repository includes deterministic synthetic trial-level records at:

```text
data/synthetic/life_satisfaction_iat_synthetic.csv
```

The synthetic records are generated by:

```powershell
python scripts/generate_synthetic_life_satisfaction_iat.py
```

The generator uses fixed seed `20260531`. It creates 180 synthetic participants, critical blocks 3 and 5, and 20 trial-level records per participant per critical block. The file includes the columns needed by the life-satisfaction preprocessing and angular-profiling code, including participant placeholders, block and trial order, response labels, latency, accuracy/error fields, stage/congruency labels, and display order.

These records contain no real participant identifiers and no copied raw trial records. They are for code execution and reviewer inspection only. They preserve the non-identifying structure needed to exercise the pipeline, but they are not intended to reproduce the empirical estimates exactly.

Validate the synthetic data with:

```powershell
python scripts/validate_synthetic_life_satisfaction_iat.py
```

Run the synthetic life-satisfaction code path with:

```powershell
python scripts/run_external_leverage_analysis.py --use-synthetic-life-data
```
